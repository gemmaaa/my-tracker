# Tra-Tra-Tracker! 💅✨

A lightweight, private tracker that runs entirely in your browser. Everything is stored locally on your device.

## Overview
- **Main Log:** Quick entries with notes, emoji categories, ratings, and tags
- **Collections:** Track books, movies, series, or create custom categories (podcasts, games, restaurants, etc.).
- **Calendar:** Color-coded monthly view showing log days, collection days, or both.
- **Stats:** Day streaks, usage patterns, top-rated items, and tag trend charts.
- **Customizable:** 4 color themes, 3 interface languages (English, Spanish, Catalan), and full CSV export for both logs.

## How to Install

### iPhone / iPad (Safari)
1. Open `https://gemmaaa.github.io/my-tracker/` in **Safari**.
2. Tap the **Share** button (box with an upward arrow).
3. Tap **Add to Home Screen**, then tap **Add**.

### Android (Chrome)
1. Open `https://gemmaaa.github.io/my-tracker/` in **Chrome**.
2. Tap the **three dots (⋮)** in the top right.
3. Tap **Add to Home screen** (or **Install app**).
